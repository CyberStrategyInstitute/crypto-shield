# Research Note 003: Actor attribution and privileged access

Status: Historical draft under revalidation. Integrity review: November 7, 2026. Threats: CS-INS-01, CS-INS-03, CS-DFI-01.

This update does not complete the historical investigation. Earlier incident amounts, attribution conclusions, calibrated-score claims, and prevention estimates are not adopted as verified findings. The [original note](https://github.com/CyberStrategyInstitute/crypto-shield/blob/051a317fb72db38f11d8928fddd5c506d24d468a/research/003_dprk_attribution_analysis.md) remains in Git history for audit.

## Evidence needed

Reconstruct original disclosures, code history, transactions, access records, and official allegations for each proposed case. External state actors, hired infiltrators, deceived employees, and malicious insiders are not mutually exclusive. Separate identity, access path, control weakness, intent, and liability.

## Interim guidance

Privileged access or an old code change does not establish malicious insider intent. Do not require an insider-first conclusion or a fixed waiting period before reporting supported facts.
