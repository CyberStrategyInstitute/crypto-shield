# AI agent or delegated signing compromise

Use during: Unexpected tools, memory changes, permissions, spawning, signing requests, or financial effects. This is an adaptable response procedure; only authorized responders should operate production controls. Physical safety comes first.

## Observe and classify

Open a decision record using the [incident log](../tools/templates/incident-log.json). Assign incident lead, technical responder, evidence owner, and communication/legal owner as appropriate. One person may cover roles, but preserve independent approval for consequential changes.

## Contain within authority

1. Stop new agent authorizations at an independent policy/signing boundary and halt spawning and shared workflows. Preserve prompts, memory provenance, tool calls, policy versions, and signed intents.
2. Inventory sessions, delegates, modules, recovery roles, signer credentials, and already approved actions with WKS-11. Apply WKS-12 invalidation; identify uncancellable actions.
3. Apply OCM-11 combined budgets and AAS-11 independent approval. Inspect retries and workers across agents, wallets, and chains rather than treating one process stop as containment.

## Stop conditions and escalation

Prompt repair or process shutdown alone cannot cancel broadcast transactions, unused permits, or stolen signer credentials. If exposure, authorization, or a safe action cannot be established, isolate the uncertain path and escalate to an independently verified qualified responder. Never request or disclose seeds or private keys in a report.

## Verify and hand off

Attempt denied actions in a safe environment using stale sessions, altered intent, replay, concurrent requests, and spawned workers. Record residual exposure before reauthorizing.

Record owner, action, UTC time, evidence, expected result, observed result, residual risk, and approval to resume. Do not mark success merely because an action was attempted. Use the [tabletop pack](../tools/tabletop-exercises.md) to rehearse without live funds or real emergency notifications.
