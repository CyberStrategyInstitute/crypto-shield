# Source and case review checklist

- [ ] Read the original artifact; record publisher, URL, publication/update date, event date or range, and actual review date.
- [ ] Separate allegations, judicial findings, affected-party accounts, vendor telemetry, and analyst inference.
- [ ] Explain the threat-ID mapping. Use provisional mapping or a new justified class when the mechanism does not fit existing IDs.
- [ ] Record alternative explanations, contrary evidence, source access limits, and later-correction needs.
- [ ] Separate direct loss, gross funds obtained, affected value, frozen/seized funds, return, compensation, and restitution. Preserve currency and valuation date.
- [ ] List controls actually established as present separately from candidate mitigations. Explain the bypass and acceptance test; do not assert a counterfactual prevention percentage.
- [ ] Link the report, event, research lesson, taxonomy entry, playbook, and exercise. Exclude personal secrets and unnecessary victim detail.
- [ ] Run repository validation and obtain independent review before changing source-checked draft status to final intelligence.

One report per category establishes example coverage only. It does not establish prevalence, research saturation, or the biggest loss in that category.
